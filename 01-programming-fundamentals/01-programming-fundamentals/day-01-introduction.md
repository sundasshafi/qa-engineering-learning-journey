## 1. What Is Programming?

Programming is the process of writing instructions that a computer can execute to perform a task.

For example, a program can calculate a total, validate an email address, or check whether a login form displays the correct error message.

As an SQA Engineer, I will use programming to automate repetitive testing activities and verify application behavior.

## 2. What Is a Programming Language?

A programming language allows us to write instructions that a computer can process.

Examples include:

- JavaScript
- TypeScript
- Python
- Java
- C#

## 3. What Is TypeScript?

TypeScript is a programming language built on JavaScript that adds static type checking.

Types help identify certain mistakes before the code runs. TypeScript code is transformed into JavaScript for execution.

I will learn TypeScript because it works well with Playwright and supports maintainable automation projects.

## 4. What Is Test Automation?

Test automation uses code and tools to execute tests and check whether an application behaves as expected.

For example, an automated login test might:

1. Open the login page.
2. Enter a username and password.
3. Click the Login button.
4. Verify that the dashboard appears.

Playwright will be our main browser automation tool later in this journey.

## 5. Important Terms

- **Program:** Instructions written to perform a task.
- **Syntax:** Rules for writing valid code.
- **Variable:** A named place to store a value.
- **Function:** A reusable block of code that performs a task.
- **Assertion:** A check that verifies whether an actual result matches an expected result.
- **Bug:** A defect that causes an application to behave incorrectly.

## 6. Connection to My SQA Work

In manual testing, I execute test steps and compare actual results with expected results.

In automation, I will write code to perform those steps and assertions to verify the results.
